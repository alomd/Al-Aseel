# 👑 حلواني الأصيل بسوهاج | Al-Aseel Confectionery

الموقع الرسمي والتفاعلي لحلواني الأصيل بمحافظة سوهاج، صانعو أشهى الحلويات الشرقية بالسمن البلدي الفلاحي الصافي، والتورتات الملكية والجيلاتو الإيطالي.

---

## ⚡ البنية التقنية (Pure Static Architecture - مثل CODX):
تم تحويل المشروع بالكامل إلى بنية ويب نقية وخفيفة لا تتطلب أي بناء (`No Build / No Node.js`):
- **HTML5 نقي وديناميكي**: [index.html](file:///c:/Users/AL3OMDA2001/Desktop/Al-Aseel%20Confectionery%20Project/index.html)
- **Tailwind CSS عبر CDN**: تنسيقات عصرية وسريعة وفائقة الاستجابة.
- **Vanilla JavaScript**: ملف تفاعلي نقي [script.js](file:///c:/Users/AL3OMDA2001/Desktop/Al-Aseel%20Confectionery%20Project/script.js) لإدارة السلة، وحاسبة التورتات، والوضع الليلي، والخرائط.
- **بيانات مستقلة**: ملف [data.js](file:///c:/Users/AL3OMDA2001/Desktop/Al-Aseel%20Confectionery%20Project/data.js) يضم الأصناف، الفروع، والتقييمات.

---

## 🚀 طريقة التشغيل:
- اضغط مرتين على ملف **`index.html`** مباشرة لفتح الموقع في أي متصفح بدون تشغيل سيرفر محلي.

---

## 📂 هيكل ملفات المشروع:
```text
Al-Aseel Confectionery Project/
│
├── index.html                  # الصفحة الرئيسية للموقع
├── script.js                   # المحرك التفاعلي للموقع (Vanilla JS)
├── data.js                     # بيانات المنتجات والفروع والتقييمات
├── style.css                   # التنسيقات والخطوط المخصصة
├── images/                     # صور المنتجات وتورت المناسبات والفروع
└── favicon.svg                 # أيقونة وشعار الموقع
```

---

## 🌐 النشر على GitHub Pages:
1. ارفع المشروع إلى مستودع GitHub الخاص بك.
2. توجه إلى **Settings** > **Pages**.
3. اختر **Deploy from a branch** وحدد فرع `main` والمجلد `/ (root)`.
4. اضغط **Save** وسيعمل الموقع أونلاين فوراً دون الحاجة لأي GitHub Actions.
