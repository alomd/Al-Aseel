# 🍰 حلواني الأصيل بسوهاج - Al-Aseel Confectionery

الموقع الرسمي لحلواني الأصيل بمحافظة سوهاج.

## 🚀 كيفية الاستخدام

فقط افتح ملف `index.html` في المتصفح مباشرة!

## 📁 هيكل الملفات

```
├── index.html          # الصفحة الرئيسية (افتح هذا الملف)
├── assets/
│   ├── index.js        # كود JavaScript المجمع
│   └── favicon.svg     # أيقونة الموقع
├── images/             # صور المنتجات والفروع
└── favicon.svg         # أيقونة الموقع
```

## 🌐 النشر على GitHub Pages

1. ارفع هذا المجلد على GitHub كـ Repository جديد
2. اذهب إلى **Settings** > **Pages**
3. اختر **Source**: `Deploy from a branch`
4. اختر **Branch**: `main` و **Folder**: `/ (root)`
5. اضغط **Save**
6. الموقع سيكون متاح على: `https://username.github.io/repository-name/`
